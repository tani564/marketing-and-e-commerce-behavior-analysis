:

🛒 Marketing & E-Commerce Customer Behaviour Analysis

📌 Project Overview
An end-to-end data analytics project uncovering how digital marketing channels and user devices drive online sales. By analyzing customer journeys—from initial clicks (Traffic_Source) and browsing engagement (Session_Duration_Min, Pages_Viewed) to cart additions (Cart_Added) and final revenue (Order_Value_INR)—this study turns raw e-commerce data into actionable growth strategies.
🗂️ Project Architecture
• 📊 ecommerce_behaviour.csv — Structured dataset capturing customer demographics, marketing traffic sources, device types, and purchase values.
• 🐍 behaviour_analysis.py — Automated Python pipeline (Pandas, Matplotlib, Seaborn) calculating conversion rates, cart abandonment patterns, and visual performance charts.
• 📝 PROJECT_SUMMARY.md — Executive documentation detailing KPIs, audience segmentation, and data-backed business recommendations.
💡 Key Insights & Impact
• 🚀 Top Revenue Drivers: Google Search and Email Campaigns delivered the highest conversion rates and order values, led strongly by the 25–44 age group.
• 📱 Mobile Cart Drop-Off: Instagram Ads drove strong mobile traffic and cart additions (Cart_Added = Yes), but showed high checkout abandonment—pointing to a prime opportunity for retargeting ads and faster mobile checkout.
• 💻 Desktop vs. Mobile: Desktop shoppers spent more time browsing per session and generated higher average order values than mobile users.
🛠️ Tech Stack: Python • Pandas • Matplotlib • Seaborn • GitHub
